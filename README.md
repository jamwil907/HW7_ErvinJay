Download the project

Go to: https://github.com/jamwil907/HW7_ErvinJay

Click Code → Download ZIP.

Extract the ZIP to a folder, for example C:\HW7_ErvinJay.

Open in Visual Studio

Open Visual Studio.

Select File → Open → Project/Solution.

Open TuringMachine.slnx (or TuringMachine.sln if that’s the file you have).

Build the project

Select Build → Build Solution.

Make sure the build completes with no errors.

Run the program

Press F5 (or click the green “Run” button).

A console window will appear.

Enter the test strings

When prompted, enter each of the required strings one at a time:

0#

01#10

#10

0100#0010

010#010

For each string, the program prints:

The current state of the machine

The complete tape contents

The head position on the tape
